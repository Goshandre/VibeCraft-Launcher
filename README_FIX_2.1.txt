VibeCraft Launcher 2.1 Fix Beta

Установка:
1. Распакуйте весь архив в отдельную папку.
2. Запустите install_dependencies.bat (если зависимости уже установлены, шаг можно пропустить).
3. Запустите run.bat.

Исправления:
- Добавлена отсутствовавшая функция выхода из аккаунта (исправляет AttributeError: logout).
- После входа кнопка входа скрывается, вместо неё показывается выход из аккаунта.
- Добавлена кнопка ВЫХОД в нижней части главного окна.
- Добавлено окно необработанной ошибки с подробностями и копированием текста.
- Кнопка Играть сохраняет автоматическую установку выбранной версии, если её ещё нет.
- Запуск Java остаётся без видимого окна консоли на Windows; лаунчер сворачивается при запуске игры и возвращается после её закрытия.

Важно:
- Профили здесь локальные/offline. Это не Microsoft OAuth и не подходит для серверов online-mode.
- Выбор PNG скина/плаща пока сохраняет файлы локально. Для фактического отображения в игре необходим совместимый клиентский мод и/или серверная интеграция; они в эту сборку не включены. Не вводите пароль Microsoft в локальную форму.
- Сборка проверена на синтаксис Python, но запуск Minecraft на Windows в этой среде не тестировался.
