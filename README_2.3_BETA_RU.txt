VibeCraft 2.3 — каталог Vanilla / Forge / Fabric (бета)

Что изменено:
- Убраны отдельные кнопки установки Fabric и Forge из главного окна.
- Список версий теперь формируется по официальному списку релизов Minecraft,
  метаданным Fabric и официальному promotions-файлу Forge.
- Варианты показываются в одном списке: "версия | Vanilla", "версия | Forge",
  "версия | Fabric".
- При выборе Forge/Fabric лаунчер пытается установить загрузчик и запускает его профиль.
- Старые папки Minecraft и профили пользователя не удаляются.

Ограничения:
- Каталог зависит от доступности официальных метаданных и API minecraft-launcher-lib.
- Это бета-интеграция Forge/Fabric; старые версии и необычные сборки могут требовать
  отдельной проверки.
- Реальный клиентский мод VibeCraft Cosmetics, который отрисовывает скины/плащи в игре,
  в этой сборке НЕ реализован. PNG по-прежнему сохраняются локально. Не выдавайте это
  за работающую игровую косметику. Для сетевого показа другим игрокам потребуется
  сервер/клиенты с поддержкой VibeCraft Cosmetics.
- Вход остаётся локальным offline-профилем; он не заменяет Microsoft authentication.

Установка:
1. Распакуйте архив в новую папку.
2. Запустите run.bat.
3. Обновите список версий кнопкой ⟳.
4. Выберите вариант в общем списке и нажмите «Играть».

Проверено: компиляция Python и целостность ZIP. Не выполнялся полноценный запуск Minecraft.
