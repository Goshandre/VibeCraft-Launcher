VibeCraft Launcher 2.4 — исправления каталога и PNG-скинов

Что изменено:
- Каталог Minecraft берётся из официального Mojang version manifest.
- Vanilla показывается для каждого стабильного релиза.
- Forge и Fabric добавляются только для версий, которые присутствуют в официальных метаданных соответствующих загрузчиков.
- Установка Forge/Fabric выполняется через совместимые функции minecraft-launcher-lib; ошибки показывают конкретную причину.
- Скины PNG 64x64/64x32 принимаются; квадратные PNG большего размера (например 128x128) автоматически приводятся к 64x64.
- Папка выбранных текстур: %USERPROFILE%\VibeCraft\.minecraft\vibecraft_skins.

ВАЖНО:
1. Это исправление загрузчика и импорта файла скина. Оно само по себе НЕ устанавливает игровой мод VibeCraft Cosmetics и не меняет скин в официальном профиле Microsoft/Mojang.
2. Чтобы скин отображался в самой игре, нужна интеграция с игровым модом или официальная авторизация Microsoft и поддерживаемый способ смены скина. Для показа другим игрокам нужна совместимая серверная/клиентская система.
3. Невозможно обещать Forge/Fabric для абсолютно каждой версии Minecraft: загрузчики существуют не для всех версий. Список показывает реально опубликованные варианты.
4. Проверены компиляция Python и целостность ZIP. Реальную загрузку Forge 1.12 и запуск Minecraft на компьютере пользователя здесь выполнить невозможно; если ошибка повторится, пришлите её текст и файл logs/latest.log.

Установка:
- Распакуйте архив в новую папку, не поверх старой.
- Запустите install_dependencies.bat.
- Затем run.bat.
- Обновите список версий кнопкой ⟳ и выберите, например, 1.12 | Forge.
