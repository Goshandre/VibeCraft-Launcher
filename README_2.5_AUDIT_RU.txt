VibeCraft Launcher 2.5 — аудит и визуальная доработка

Что изменено:
- Исправлена установка Fabric и Forge: используется единый API mod_loader из minecraft-launcher-lib 8.x.
- Устранена несовместимость старых вызовов mcl.fabric / mcl.forge с библиотекой 8.x.
- После установки проверяется профиль загрузчика, а ошибки показывают понятное сообщение.
- Обновлён интерфейс: увеличено окно, улучшены отступы, заголовки, кнопка запуска и индикатор прогресса.
- При обновлении каталога сохраняется выбранная версия, если она всё ещё доступна.

Ограничения:
- В каталоге отображаются только версии, для которых обнаружена доступность загрузчика в метаданных.
- Minecraft 1.12 Forge обычно означает конкретную версию игры 1.12.2; выбери именно 1.12.2, если нужен Forge для этой ветки.
- Выбор PNG пока импортирует текстуру локально. Для фактического отображения скина/плаща в игровом окне требуется отдельный совместимый клиентский мод.
- Офлайн-профиль не авторизует на online-mode серверах.

Проверки:
- Python compileall / py_compile.
- Проверка целостности ZIP.
- Реальный запуск Minecraft и сетевые загрузки в этой среде не выполнялись.
